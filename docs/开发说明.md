# 仓库说明（给开发者）

这是一个 Windows 桌面程序「即译」的源码仓库。用户向说明见 [README](../README.md) 与 [使用说明](使用说明.md)。

## 目录

```
.
├── 项目代码/            Electron 宿主壳（主进程 / 渲染进程 / 核心层 / 脚本）
│   ├── src/core/        纯 Node 核心：截图、OCR、翻译链、配置、密钥、轮询
│   ├── src/main/        主进程：窗口、托盘、热键、IPC、穿透轮询、启动器配合
│   ├── src/renderer/    hud / overlay / ball / settings / onboarding
│   ├── scripts/         launch / smoke / package-win / package-release / OCR 辅助
│   ├── launcher/        C# 启动器源码（打包时用 csc 编成根目录 exe）
│   └── runtime/         llama.cpp 运行时与 ONNX OCR 模型（不入库，见下）
├── 项目测试/            单元 / 集成 / OCR 精度测试，合成图与自检报告
├── dsh-plugins/         （可选）DeepSeek Harness 侧插件
└── docs/                使用文档与截图
```

## 本地构建

前置：Windows 10/11 x64、Node.js 24+、pnpm、（打包时）系统自带 .NET Framework 的 `csc.exe`。

```powershell
cd 项目代码
pnpm install
node scripts\launch.js                        # 开发态启动
node 项目测试\run-all.js                      # 全量测试（27 个文件）
node scripts\smoke.js                         # 应用自检：截图 + report.json
node scripts\package-win.js                   # 本地便携版 dist\win-x64
node scripts\package-release.js --no-model    # 对外发布包（剥 userdata、附许可）
```

## 仓库里没有的大文件

以下内容因体积或许可原因不入库，构建/运行前需自行准备：

| 路径 | 内容 | 获取方式 |
| --- | --- | --- |
| `项目代码/runtime/llama/` | llama.cpp b12000 win-cpu-x64（约 60 MB） | ggml-org/llama.cpp releases `llama-b12000-bin-win-cpu-x64.zip` |
| `项目代码/runtime/ocr-rapid/models/` | PP-OCRv4 中/日/韩 rec + 字典（约 48 MB） | ModelScope `RapidAI/RapidOCR` |
| `userdata/models/*.gguf` | 离线翻译模型 | ModelScope `Tencent-Hunyuan/HY-MT1.5-1.8B-GGUF` |

`node_modules/` 与 `dist/` 也不入库。

## 关键约定

- **截图只走主进程**：渲染进程与插件都不得直接调用截屏 API。
- **IPC 契约单一来源**：`src/shared/ipc-channels.js`，新增通道要三处同改（契约 / `main/ipc.js` / `preload/index.js`），
  测试会静态比对。
- **密钥永不落明文**：配置里只有 AES-256-GCM 密文，日志与 IPC 一律掩码。
- **测试用合成图**，不把真实桌面截图放进仓库。
- 更多踩坑记录见 [项目代码/AGENTS.md](../项目代码/AGENTS.md) 第 6 节（按轮次记录）。

## 发布到 GitHub（可选）

仓库里附了一个不依赖 git 客户端的发布脚本：`项目测试/tools/gh-publish.ps1`（只调 GitHub REST API）。

```powershell
$env:DSH_GH_PAT = 'github_pat_xxx'          # 需要 Contents: write + Releases: write
powershell -ExecutionPolicy Bypass -File 项目测试\tools\gh-publish.ps1 `
  -Owner <你的用户名> -Repo jiyi-desktop-translator `
  -Tag v1.0.0 -Zip 'dist\即译-1.0.0-portable-win-x64-nomodel.zip'
```

它会：逐个文件建 blob → 建树 → 提交 → 推 `main` → 建 Release → 流式上传资产。
注意：空仓库第一次要先有提交（脚本会以现有分支头为父提交）；资产名请用 ASCII，中文名会被 GitHub 丢弃。
