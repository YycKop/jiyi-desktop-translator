# 即译 使用说明

> 适用于 v1.0.1 Windows x64 免安装版。
> 遇到问题先看文末「常见问题」，再看 `userdata\` 下的日志。

---

## 一、安装与启动

1. 解压 zip 到任意目录（**不要**放 `C:\Program Files`，程序要往自己目录写 `userdata\`）。
2. 双击 `即译.exe`。
3. 首次启动弹出欢迎引导：
   - 选目标语言（默认「中文（简体）」）
   - 需要的话在这一步配置 API 或离线模型，也可以稍后在设置里做
4. 完成后主界面是一个小浮窗，托盘区（右下角 `^`）有图标。

> **SmartScreen 提示**：本程序未购买代码签名证书，Windows 会对所有未签名程序弹「已保护你的电脑」。
> 点「更多信息」→「仍要运行」即可。

> **看不到窗口**：再双击一次 `即译.exe`，会把设置窗口叫到前台；也可能是浮窗在屏幕边缘之外，按 `Ctrl+Shift+Y` 唤回。

## 二、三种用法

### 1. 框选翻译（最常用）

1. 按 `Ctrl+Shift+T`（或托盘「输入翻译」旁的相关动作）。
2. 屏幕变暗，拖出一个矩形，覆盖要翻译的文字。
3. 松手 → 出现译文浮窗。框选区域会记住，按 `Ctrl+Shift+R` 可以重译同一块。

译文浮窗左下角的「原文 ▸」可以展开原文；底部显示引擎与耗时。

### 2. 定时轮询（看视频 / 盯字幕）

浮窗 `⏸/▶` 按钮或 `Ctrl+Shift+P` 启动定时翻译：每隔 N 秒自动重译上次框选的区域。
未变化的画面会走帧指纹跳过，不重复调用接口。

轮询间隔在「设置 → 通用 → 轮询」里选（300 ms ~ 5 s）。间隔越短越实时，CPU 也越高。

### 3. 字幕条模式（游戏 / 视频专用）

「设置 → 通用 → 浮窗 → 浮窗样式」切到「字幕条模式」：

- 细长透明条，只留描边文字，尽量不挡画面
- 顶部正中一个握把：**点一下**展开/收起按钮，**按住拖动**移动位置
- 左右边缘拖动改宽度，底部拖动改高度（设置页也能填具体像素）
- 字号可调，`12–48 px`；译文太长会自动缩小字号以适应条内空间
- 可开「字幕底衬」给文字加一层淡底，适合亮画面

## 三、联网翻译（可选）

「设置 → API 接口 → 添加接口」：

1. 选预设（DeepSeek / OpenAI / 通义千问 / 自建 OpenAI 兼容网关）或手填 baseURL 与模型名。
2. 填 API Key → 「验证并添加」。测试通过后会显示掩码（形如 `sk-****abcd`）。
3. 可添加多个接口，拖动排序，按顺序重试：主接口 5 秒、备用 3 秒超时，只看失败/超时才切换。

**密钥安全**：Key 用 AES-256-GCM 加密后存 `userdata\config.json`，密钥由本机指纹派生；
换机器或重装系统后需要重新填 Key。日志与界面都不会出现明文。

## 四、离线翻译（可选）

1. 下载 GGUF 模型（推荐 `HY-MT1.5-1.8B-Q4_K_M.gguf`，约 1.08 GB）。
2. 放到程序目录 `userdata\models\`。
3. 设置 →「离线模型」→ 刷新，能看到模型即可。
4. 可以在通用页把「翻译优先级」设为「离线优先」：先走本机模型，失败再用联网接口。

内存说明：模型常驻约 2.0–2.2 GB；默认空闲 10 分钟自动卸载（「离线模型」页可改，0 = 常驻）。

## 五、外观自定义

「设置 → 外观」：主题色、背景色、字体颜色（可跟随背景）、不透明度、背景模糊、圆角、
**背景图**（浮窗与设置页各自一张、各自一条不透明度，可选铺满/完整/平铺），带实时预览。

## 六、热键

| 动作 | 默认值 | 说明 |
| --- | --- | --- |
| 框选翻译 | `Ctrl+Shift+T` | 拖框选区 |
| 重译上次区域 | `Ctrl+Shift+R` | 用记住的区域再翻一次 |
| 暂停 / 继续 | `Ctrl+Shift+P` | 也可用浮窗 `⏸` 或 `Esc` |
| 显示 / 隐藏浮窗 | `Ctrl+Shift+Y` | |
| 收起为悬浮球 | `Ctrl+Shift+U` | 点球展开选项气泡 |

设置页「热键」里点「按下新组合键」即可重设，冲突会提示。

## 七、数据与卸载

| 位置 | 内容 |
| --- | --- |
| `userdata\config.json` | 配置（含加密后的 Key） |
| `userdata\models\` | 离线模型 |
| `userdata\logs\` | 运行日志（不含 OCR 全文与译文） |
| `userdata\theme\` | 导入的背景图 |

- **卸载**：直接删除整个文件夹。
- **只想保留配置**：删掉 `app\` 与 `即译.exe`，保留 `userdata\`。

## 八、常见问题

**Q：双击没反应？**
看 `userdata\launcher.log` 与 `userdata\startup-error.log`。启动器会在崩溃时自动用兼容模式重试一次。

**Q：托盘图标找不到？**
部分 Windows 会话里通知区域拒绝注册第三方图标（系统限制）。此时程序会自动显示悬浮球作为常驻入口；
也可以再双击一次 `即译.exe` 唤出设置窗口。

**Q：识别不准 / 出现多余标点？**
- 小字号文字：框大一点，或调高屏幕缩放。
- 亮底浅字：设置里开「字幕底衬」，或换「识别语言」为具体语种（自动识别靠置信度 + 字形占比，混排时可能判错）。
- 日文 / 韩文：确认引擎是 ONNX（设置 → 通用 →「识别引擎」选「自动」或「ONNX」），并把「识别语言」设为日文或韩文。

**Q：字幕条太挡画面？**
切字幕条模式，或调低不透明度、调窄宽度；字幕条模式下正文点击可穿透到下层窗口。

**Q：CPU 占用高？**
把轮询间隔调到 500 ms 以上；静态画面会自动跳过 OCR 与翻译，视频场景跳过不会那么频繁。

**Q：离线不可用？**
确认模型在 `userdata\models\`、文件名以 `.gguf` 结尾；日志 `userdata\core.log` 会写明找不到模型还是端口占用。
