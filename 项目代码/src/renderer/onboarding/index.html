即时翻译，沟通无界

把屏幕上的文字，翻译成母语

框选任意区域，助手会识别其中的文字并翻译到浮窗上。截图只发生在这个区域内，识别与离线翻译全部在本机完成。

  • 默认热键 Ctrl+Shift+T 框选区域，热键可在设置中修改。
  • 浮窗默认置顶、半透明，不抢焦点，可随时收起为悬浮球。
  • 支持联网 API 与本地离线模型两种方式，可自动降级。

离线模型（可选）

离线翻译使用 llama.cpp + 混元 HY-MT1.5-1.8B 的 GGUF 量化模型（推荐 2-bit ≈ 574MB）。 模型文件较大，未随安装包分发，需要单独获取后在此选择；也可以先跳过，只使用联网 API。

跳过之后仍然可以随时在「设置 → 离线模型」中补配。

联网翻译接口（可选）

填入任意 OpenAI 兼容接口即可获得更好的译文质量，支持 DeepSeek / OpenAI / Claude / Gemini 等预设。 可以配置多个接口组成「主用 → 备用」链，前一个失败或超时会自动切到下一个。

尚未配置接口

密钥使用系统机器指纹派生的 AES-256-GCM 加密后保存在本机，界面只显示掩码。

准备就绪

按下热键框选一段文字即可开始。浮窗标题栏的 ⚙ 按钮随时可以打开设置。

  • 打开设置：点浮窗标题栏的 ⚙；再次双击程序图标；或右键托盘图标 →「设置」。
  • 托盘图标可能被 Windows 收进右下角 ^ 溢出区，可拖到常显区域。
  • 游戏/视频建议使用「无边框窗口化」，可获得更好的置顶与取词效果。
  • 若目标程序以管理员权限运行，请以相同权限启动本助手，否则可能取不到词。
